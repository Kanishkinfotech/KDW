# KDW - Enterprise E-Commerce Platform

Enterprise e-commerce platform featuring a modern React frontend and a robust Node.js/Express backend with Prisma ORM.

## Project Architecture

- **`front end/`**: Modern client-side application built with React, Vite, TailwindCSS, Zustand, and Framer Motion.
- **`server/`**: RESTful backend API powered by Node.js, Express, TypeScript, Prisma ORM, JWT authentication, and Razorpay integration.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Frontend Setup
```bash
cd "front end"
npm install
npm run dev
```

### Backend Setup
```bash
cd server
npm install
npm run dev
```
